# 演示视频 · 分镜与旁白稿

> 成片：`docs/demo.mp4` —— **1280×720 / 3:05 / 2.8MB / H.264 + faststart / 无音轨**
> 画面全部来自**线上站点真实交互**（`https://mem-scheduler-nwdvyg6mjmb.qoder.zone`），无人工剪辑、无假数据。
> 时间码来自 `docs/demo-timeline.json`，是脚本按帧间隔实测换算的，不是估算。

## 怎么重跑

```powershell
npm install --no-save ffmpeg-static        # 一次性，80MB 依赖不写进 package.json
node scripts/make-demo-video.mjs           # 默认输出 docs/demo.mp4
node scripts/make-demo-video.mjs --scenes=2 --out=docs/_smoke.mp4   # 只录前 2 镜，快速自检
```

录制方式：CDP 直驱 headless Chromium（不装 Playwright），`Page.startScreencast` 只在画面变化时出帧，
每帧时长按真实间隔回灌给 ffmpeg concat。**静止段不掉时长**靠字幕条底部那条进度线保证有帧可出。

字幕条是注入到页面的固定层，坐标全部在 Node 侧算好再插值 —— 页面里没有 `W`/`H` 变量，
直接写裸标识符会 `ReferenceError`，而且 `Runtime.evaluate` 不抛 `exceptionDetails` 时是静默失败。

## 配音与上传（需要本人操作）

1. 视频**没有音轨**，两种用法任选：
   - 直接当静音演示发（配帖内文字说明），最省事；
   - 或按上表旁白配音。用剪映/CapCut 导入 `docs/demo.mp4`，逐镜贴文本自动朗读，对齐时间码即可。
2. 帖子要的是**公开视频链接**，所以必须上传到一个可外链的平台（B 站 / 视频号 / YouTube 均可），拿到 URL 后填进 `docs/参赛帖素材.md` 第 5 节的 `{{your-video-url}}`。
3. 发布前自查一遍画面：视频里出现了脱敏后的教师姓名（如「岑静姝」「言未晞」），这些是映射名、不是真人；但如果你不希望姓名出镜，告诉我，我把字幕条改成打码版重录。
